Igareck AntiDPI Strategies + Bol-Van Zapret2
CLI Version 1.0 | macOS 26+ ARM64/x64 | УСТАНОВКА
===========================================================================

484 стратегии: 45 Golden + 439 Silver; 23 семейства.
Полный справочник: README_Стратегии_macOS_v1.0.txt.

ТРЕБОВАНИЯ
- macOS 26 или новее; Apple Silicon ARM64 и Intel x64.
- Штатный /usr/bin/python3 (Python 3.9+), Xcode Command Line Tools.
- Homebrew для автоматической установки pkg-config и LuaJIT, если их нет.
- root для PF и BPF. SIP, kext, Network Extension и перезагрузка не нужны.
- Активный физический IPv4 Ethernet/Wi-Fi адаптер с шлюзом по умолчанию.

УСТАНОВКА
Распакуйте архив и выполните:
  tar -xzf Igareck_AntiDPI_CLI_v1.0_macOS.tar.gz
  cd Igareck_AntiDPI_CLI_v1.0_macOS
  bash INSTALL.sh

Enter выбирает /opt/igareck-antidpi. Можно указать другую новую пустую папку.
Для установки без автоматического входа в меню:
  bash INSTALL.sh --no-launch

Используется только проверенный Zapret2:
коммит 4a33055448ce5f4e7acc704e1fbe0d8a8a6aa08d;
SHA-256 tar.gz f4268bc612ee3ee31176bc3b5cb5c8bd6b9e1c2a5bd3b89783161b24b95bf620.
Во время установки скачиваются исходники, применяется собственный Darwin patch,
собирается macws2 и проверяются параметры/Lua всех 484 стратегий.
Вариант latest намеренно не поддерживается: patch к непроверенному коду не применяется.

ЗАПУСК
  sudo bash /opt/igareck-antidpi/START.sh
или из любой папки:
  igareck-antidpi
При выборе соответствующей опции ярлыки создаются в Desktop/Igareck_AntiDPI.

Выберите физический адаптер и TCP-порты. Enter в поле портов = все.
Примеры: 443 или 80,443,1000-2000.
F1/s — другая стратегия; F2/r — перезапуск; F3/i — адаптер/порты;
Ctrl+C/q — остановка и очистка.

КАК РАБОТАЕТ MACOS-ВЕРСИЯ
Zapret2 официально не поддерживает macOS. Эта версия сохраняет его движок и Lua-стратегии,
но заменяет NFQUEUE на PF/pflog + BPF:
1. Собственный block out log quick направляет копию исходного IPv4 TCP-пакета в pflog,
   а оригинал блокируется.
2. macws2 выполняет выбранную Lua-стратегию и отправляет пакеты через BPF на физический адаптер.
3. Входящие SYN/ACK журналируются для conntrack/AutoTTL без quick; окончательное решение
   остаётся за остальными PF-правилами. Входящие пакеты повторно не отправляются.

Правила находятся только в com.apple/igareck_<ID>. /etc/pf.conf не изменяется.
PF включается через pfctl -E с отдельным token и освобождается через pfctl -X.
При остановке или recover очищаются собственный anchor и созданные pflog 9–31.
При внезапном завершении родительского CLI guard завершает движок и очищает перехват.

ОГРАНИЧЕНИЯ
- Только исходящий IPv4 TCP/TLS, как в текущем каталоге; QUIC/UDP и IPv6 не перехватываются.
- Полный VPN/TUN может направлять трафик мимо выбранного физического адаптера.
  Для проверки YouTube выключите VPN/TUN. Для VPN используйте split routing, если трафик
  клиента должен проходить непосредственно через физический адаптер.
- Нужен MAC шлюза в ARP-кэше; если записи нет, установщик запуска выполняет один ARP-запрос
  при первом запуске стратегии. Смена шлюза во время работы требует F2 или перезапуска.
- Не используйте одновременно другие программы, которые перезаписывают PF.
  Команда pfctl -f /etc/pf.conf сторонней программой может удалить runtime anchor.
- Internet Sharing и не-Ethernet интерфейсы не поддерживаются.
- Успешная проверка параметров не гарантирует обход конкретного ТСПУ.

YOUTUBE
Введите youtube вместо номера, затем диапазон и параллельность 1–5.
PASS — две успешные попытки; UNSTABLE — одна. Esc останавливает проверку.
Проверка использует отдельные исходные порты и выбранный физический интерфейс.
Логи и ZIP с диагностикой сохраняются в logs/.

ЛОКАЛЬНЫЕ ИСКЛЮЧЕНИЯ
  <папка установки>/lists/ips-exclude.txt
После изменения перезапустите стратегию F2.

ВОССТАНОВЛЕНИЕ ПОСЛЕ СБОЯ
  sudo bash /opt/igareck-antidpi/START.sh recover
Удаляются только собственные правила, процессы, token и pflog этой установки.

УДАЛЕНИЕ
Стандартное, с сохранением логов и изменённых файлов:
  sudo bash /opt/igareck-antidpi/DELETE.sh
Полное, включая папку установки и логи:
  sudo bash /opt/igareck-antidpi/DELETE.sh --purge
Перед удалением требуется ввести УДАЛИТЬ или DELETE.
